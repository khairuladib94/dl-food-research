# Facilitator guide

## Recommended delivery

1. Display the workshop QR code or share the landing-page URL.
2. Ask participants to sign in to a Google account.
3. Demonstrate **Open in Colab**, **File > Save a copy in Drive**, and
   **Runtime > Run all**.
4. Session 6 participants may work through any of the five guided case studies.
5. For Session 9, assign one of the six group notebooks to each group.

## Ten-minute preflight

- Open the landing page in an incognito window.
- Open one Session 6 and one Session 9 notebook in Colab.
- Run their setup and first data-loading cells.
- Confirm the Google Drive slide folder works without owner authentication.
- Keep the backup ZIP on the presentation laptop.

## Fallback order

1. Retry the notebook in a fresh Colab runtime.
2. Use the backup ZIP from Google Drive.
3. Use local Jupyter following the optional local setup guide.

## Notes

- CPU is the default and is sufficient for the compact teaching models.
- Colab runtimes are temporary. Participants should save a copy to Drive before editing.
- The datasets are synthetic and intended only for teaching.
