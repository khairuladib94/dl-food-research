Troubleshooting

File not found

Run the first setup cell again. It downloads only the dataset required by that notebook.

Runtime disconnected

Reconnect, then use Runtime → Run all. Colab runtimes are temporary; your notebook copy remains in Drive.

Old or confusing output

Choose Runtime → Disconnect and delete runtime, reconnect, then Run all.

No GPU available

Continue with CPU. These teaching models are deliberately compact and do not require a GPU.
